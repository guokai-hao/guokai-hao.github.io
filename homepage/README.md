# Academic Homepage — Not Pure Poole Edition

A lightweight academic personal homepage adapted from **Not Pure Poole**.

Edit `_data/profile.yml`, `_data/research.yml`, `_data/publications.yml`, `_data/social.yml`, and `_config.yml` to customize the site.

For Chinese setup instructions, see `README_CN.md`.
